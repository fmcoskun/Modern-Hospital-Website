# Fotoğraf kaynakları

Tüm fotoğraflar [Openverse](https://openverse.org) API üzerinden bulunan, **CC0 / kamu malı** lisanslı görsellerdir (çoğu StockSnap); atıf zorunlu değildir, yine de kayıt tutulur. Dosyalar `public/images` altında kendi sunucumuzdan sunulur (`scripts/fetch-photos.mjs`, meta veri `src/lib/photos.json`). Kaynakta en fazla ~1000 px genişlik bulunduğundan hero ve banner'larda koyu katman kullanılır; aynı adla daha yüksek çözünürlüklü dosya konursa kod değişmez.
